# DigiShield - An AI-Powered Digital Arrest Scam Detection System

This is an **AI-powered system that detects scam language** and intimidation tactics **in live calls or messages**, particularly for **digital arrests**. It analyzes conversations, **alerts users** when suspicious patterns are identified, and **suggests safe actions**. High-risk situations may trigger optional notifications to a trusted emergency contact. The goal is to **protect users from fraud, coercion, and authority impersonation.**

## Tech Stack -
**LANGUAGE:** Python  
**SPEECH TO TEXT:** WHISPER  
**NLP MODEL:** distilBERT  
**DATASET:** CSV  
**FRONTEND:** STREAMLIT  

## Backend Info -
a DistilBERT NLP model to train our app on scam-based language  
Whisper AI for Automatic Speech Recognition (Speech to Text)  
CSV dataset which uses Binary Labelling (1 = scam; 0 = not scam.)  

This prototype was built for the IEEE Kalpana 6.0 Hack for Humanity Hackathon Feb 2026.
